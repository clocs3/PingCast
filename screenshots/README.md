# Screenshots

`screenshots/`는 실행 화면 증거를 정리할 위치입니다.

| 경로 | 역할 |
|---|---|
| `streaming/` | streaming playback test 화면 |
| `jenkins/` | Jenkins build 결과 |
| `argocd/` | Argo CD sync 결과 |
| `grafana/` | Grafana dashboard 화면 |

account ID, private URL, token, internal IP, 실제 user data가 보이는 screenshot은 넣지 않습니다.
