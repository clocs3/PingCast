# Harbor

`ci-cd/harbor/`는 원본 환경에서 private image registry로 사용한 Harbor 관련 안내 디렉터리입니다.

이 공개 repository에는 Harbor data directory, TLS private key, robot account credential, generated configuration file을 포함하지 않습니다.

image reference는 아래 placeholder 형태로만 표현합니다.

```text
registry.example.com/pingcast/<image-name>:<git-sha>
```
